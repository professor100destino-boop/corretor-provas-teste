Chave da API

Para corrigir com IA, o app precisa de uma chave da API da Anthropic (Claude). Você cria a sua e paga só pelo uso — cada correção custa poucos centavos.

Como conseguir: acesse console.anthropic.com, crie uma conta, adicione um cartão em "Billing" e depois vá em "API Keys" → "Create Key". Copie e cole aqui.

Sincronização online

Guarda turmas, alunos e notas em um servidor seu. Assim você abre o app em qualquer aparelho e os dados estão lá.

Deixe os dois campos vazios e salve para desligar a sincronização.

Dados salvos

Turmas, alunos e correções ficam guardados só neste navegador/celular. Se limpar os dados do site ou trocar de aparelho, eles se perdem.

Pra levar os dados pra outro celular, exporte um arquivo aqui e importe ele no outro aparelho.
